# Cosmos · Plataforma educativa del Sistema Solar

Proyecto integrador de Electiva I (UPT de Valencia).

## Páginas
index, galaxia, vialactea, planetas, estrellas, satelites, trivias, inscribete

## Estructura
```
cosmos/
├── index.html ... inscribete.html
├── css/style.css          (variables, Grid, Flexbox, media queries, animaciones)
├── js/
│   ├── comun.js           (menú móvil)
│   ├── datos.js           (arreglo de objetos con los planetas)
│   ├── planetas.js        (filtros, orden, modal, tabla)
│   ├── satelites.js       (arreglo de lunas + filtro)
│   ├── trivia.js          (preguntas + lógica)
│   └── formulario.js      (validación con regex)
├── img/
└── videos/
```

## Publicar en GitHub Pages
1. Crea un repositorio y sube todo el contenido de la carpeta `cosmos`.
2. Settings → Pages → Branch: `main` y carpeta `/ (root)` → Save.
3. Copia la URL pública y envíala al correo del docente.
